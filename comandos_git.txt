COMANDOS ESSENCIAIS - GIT

[INICIALIZAÇÃO E MONITORAMENTO]
git init .           -> Inicializa um repositório Git no diretório atual.
git status           -> Exibe o estado atual dos arquivos (modificados, preparados ou não rastreados).
git log              -> Exibe o histórico cronológico de commits do projeto.

[CICLO DE VERSIONAMENTO]
git add <arquivo>    -> Prepara um arquivo específico para o próximo commit (staging area).
git add .            -> Prepara todas as alterações do diretório para o commit.
git commit -m "msg"  -> Grava permanentemente as alterações preparadas no histórico.

----------------------------------------------------------------------
FLUXO DE TRABALHO PADRÃO (WORKFLOW)

1. Preparação: Criar ou acessar o diretório do projeto via terminal.
2. Inicialização: Executar 'git init .' para começar o rastreamento.
3. Desenvolvimento: Criar ou editar arquivos.
4. Revisão: Utilizar 'git status' para verificar as modificações.
5. Seleção: Adicionar as mudanças com 'git add .' ou arquivos específicos.
6. Consolidação: Executar 'git commit -m "Descrição objetiva da alteração"'.
7. Repetição: Retornar ao passo 3 para novas implementações.
